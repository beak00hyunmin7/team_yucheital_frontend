# 유체이탈 프론트엔드

## 실행 방법

**준비물**: Python 3.10 이상 (설치할 때 "Add python.exe to PATH" 체크)

```powershell
git clone https://github.com/beak00hyunmin7/team_yucheital_frontend.git
```

1. `project_yucheital/run_test_server.bat` 더블클릭
2. 브라우저가 `http://127.0.0.1:8000/vtkjs.html` 로 열리고, 오른쪽 위가 🟢 이면 성공
3. 끌 때는 검은 창에서 `Ctrl+C`

- 이건 **테스트용 가짜 서버**(`project_yucheital/dev_server/mock_server.py`)라서 예측 그림은 진짜 AI 결과가 아닙니다. 화면 기능 확인용입니다.
- **진짜 AI 서버**를 쓰려면 AI 저장소의 `terrainFlowSim/webapp/run_windows.bat` 을 실행하고(체크포인트 `best.pt` 필요), 테스트 서버는 끈 채로 `yuche_frontend/vtkjs.html` 을 열면 됩니다.
- 서버 주소는 `yuche_frontend/vtkjs.html` 의 `DEFAULT_API` 한 줄에서 바꿉니다. 파일을 고치지 않으려면 주소 뒤에 `?api=http://IP:포트` 를 붙여도 됩니다.

## 화면 구성 (지도 우선)

지도가 화면을 채우고, 나머지는 그 위에 떠 있는 패널입니다 (`yuche_frontend/vtkjs.html` + `style.css`).
시안(목업)의 수치·색을 그대로 따릅니다: 다크 `#0d1218` 바탕, 포인트색 `#4cc3ff`(그 위 글자는 `#06202e`), 패널 폭 340px, 레일 64px, Noto Sans KR.

| 영역 | 내용 |
|---|---|
| 왼쪽 레일 | 로고 · 예측 · 기록(건수 배지) / 아래쪽에 서버 상태 점 · 테마 · 🎄 · 계정(누르면 로그인·가입 또는 이메일·로그아웃 메뉴). 상단바와 안내 배너는 없음 |
| 지도 | 예측 결과를 화면 전체에 꽉 채워(cover) 표시하고 왼쪽·아래를 어둡게 깔아 패널을 살림. 정사각 지도라 긴 변 쪽이 잘리는데, 배수구 후보가 잘리는 쪽에 있으면 보이는 창을 그쪽으로 옮김. `전체 보기` 버튼으로 잘림 없이 볼 수도 있음. **마우스 드래그로 이동, 휠·`+`/`−` 버튼·핀치·더블클릭(2.5배 ↔ 원래)으로 확대**(최대 800%, 커서 아래 점 기준). 가장자리가 화면 안으로 끌려 들어와 빈 공간이 생기지 않고, 확대해도 배수구 표시는 같은 크기로 같은 지점에 붙음. 새 결과를 받으면 처음 상태로. 배수구 후보는 그림에 굽지 않고 빨간 원(비율 좌표)과 라벨 카드로 얹음. 데이터 모드는 등고선(m)·음영기복이 있는 지도, 이미지 모드는 오버레이 |
| 왼쪽 조건 패널 | 입력 방식 · 파일 · 강우량(슬라이더 + 30/50/80 빠른 선택) · 경과 시간 · 고급 설정(이미지 색 체계, 격자 크기) · 실행. 접으면 한 줄 알약(`50mm · 18초`) |
| 오른쪽 위 칩 | 최대 침수(cm) · 5cm 이상 면적(%) = 서버 `stats`. `결과 이미지`(입력 등고선·예측·오버레이·분석 지도 모아보기), `기록` 서랍(최근 6건, 누르면 그 결과를 지도에 엶) |
| 아래 시간 슬라이더 | 시점별 예측 6장(18~120초)을 이어 재생. 재생·슬라이더를 만지면 `지도` → `시간 변화` 보기로 바뀜 |
| 입력 확인 창 | 학습 형식이 아닌 색 체계(회색조·무지개 등)라 서버가 높이로 읽어 변환했을 때: 원본 / 읽은 결과 / 예측 미리보기와 "높은 곳을 맞게 읽었나요?"(맞아요·반대예요, 색 체계 직접 선택). 바꾸면 그 자리에서 다시 예측 |
| 오류 안내 창 | 지형도·스캔 도면처럼 색이 높이가 아닌 이미지(서버 422 + `code: "unreadable_image"`): 이유와 다음 행동(DEM 올리기 · 높이를 색으로 칠한 이미지 · 샘플로 해보기) |

- 1000px 이하(모바일)에서는 지도 → 칩 → 시간 슬라이더 → 조건 패널 → 기록 순으로 세로로 쌓입니다.
- 분석 기록 화면(표)·로그인·테마·크리스마스 모드는 그대로입니다.

### 서버가 주는 값 (`POST /api/predict`)

기존 필드에 더해 이 화면이 쓰는 것들입니다. 없어도(구버전 서버·테스트 서버) 화면은 그 부분만 숨기고 동작합니다.

| 요청 필드 | 설명 |
|---|---|
| `color_scheme` | 이미지 모드. `auto`(기본) 또는 `/api/color-schemes` 의 key |
| `reverse` | 이미지 모드. `true` 면 높낮이를 반대로 해석 |

| 응답 필드 | 설명 |
|---|---|
| `stats` | `{ max_depth_cm, wet_area_pct, wet_threshold_cm }` 지도 위 칩 |
| `map_jpg_base64` | 데이터 모드의 깨끗한 지도(JPEG). 없으면 오버레이로 대체 |
| `color_info` | 이미지 모드. `{ scheme, label, auto, reversed, converted, legend, warnings }` — `converted` 면 입력 확인 창을 띄움 |
| `original_png_base64` | 서버가 색 체계를 변환했을 때 올린 원본 |
| 오류 422 + `code` | `unreadable_image` → 오류 안내 창. 그 밖의 422 는 기존처럼 알림 |

테스트 서버(`mock_server.py`)도 같은 필드를 흉내 냅니다. 파일명에 `topo` 가 들어가면 `unreadable_image` 오류를, 회색조 이미지는 변환 + 입력 확인을 시험할 수 있습니다.

## 분석 기록 저장

분석 기록은 AI 서버의 `/api/history` 에 저장됩니다(MySQL + 썸네일 파일). 로그인한 사용자 본인 기록만 보이고, 다른 PC·브라우저에서도 같은 기록이 보입니다. 목록은 최신순 최대 50건입니다.

| 동작 | API |
|---|---|
| 목록 | `GET /api/history` |
| 저장 (예측 완료 시 자동) | `POST /api/history` |
| 이름 변경 | `PATCH /api/history/{id}` (`{ name }`) |
| 삭제 / 전체 삭제 | `DELETE /api/history/{id}` / `DELETE /api/history` |

- 모든 요청에 `Authorization: Bearer 토큰` 헤더가 필요합니다. 토큰은 `/api/auth/login` 에서 받아 `localStorage['yuche_token']` 에 저장합니다.
- 비로그인 상태나 DB 가 끊긴 상태에서는 기록이 저장되지 않습니다. 저장에 실패하면 결과 안내에 한 줄로 표시됩니다.
- 예전 localStorage 기록(`yuche_history_{이메일}`)은 서버로 옮기지 않았고, 화면에도 보이지 않습니다.
- 테스트 서버도 같은 API 를 제공하지만 기록을 메모리에만 두므로 서버를 끄면 사라집니다.

## 배수구 후보 위치

`POST /api/predict` 응답의 `drain_candidate.image` `{ x, y }` 는 그림 왼쪽 위 기준 0~1 비율입니다. 예측 배수맵과 오버레이 위에 빨간 원으로 표시하고, 기록의 `drain` 에도 이 값을 저장합니다.
